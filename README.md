# Manipulator-z-elektromagnesem
Projekt studencki trójosiowego ramienia robotycznego sterowanego bezprzewodowo. Aplikacja webowa z intuicyjnymi suwakami umożliwia precyzyjną kontrolę kątów obrotu osi oraz aktywację elektromagnesu do przenoszenia obiektów. Kod zawiera firmware mikrokontrolera oraz frontend panelu sterowania.
